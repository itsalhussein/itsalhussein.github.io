# Alhussein Anwar — Portfolio

Portfolio website for Alhussein Anwar, a Senior iOS Engineer specializing in
Swift, UIKit, SwiftUI, and the responsible evolution of native products to
Kotlin/Compose Multiplatform and Flutter.

## Live site

[itsalhussein.github.io](https://itsalhussein.github.io/)

## Local development

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

## GitHub Pages export

```bash
npm run export:github-pages
```

The export command builds the site and writes the static GitHub Pages version
to `docs/`.
